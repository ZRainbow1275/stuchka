Stučka - 中国大陆劳动纠纷 AI 工作台
====================================

安装前请阅读：

1. 本软件以 GPL-3.0-only 许可证发布（见安装向导的许可页 / LICENSE-GPLv3.txt）。
2. 本软件不是律师，不提供法律意见，输出仅供参考；正式法律事务请咨询执业律师。
3. 所有案件数据默认仅存储在本机 %LocalAppData%\Stuchka\ 目录，不上云。
4. 安装包内含两个可执行文件（D1 双进程架构）：
     - stuchka.exe       Flutter 桌面主进程
     - stuchka-core.exe  Rust core 子进程（主进程启动时本地拉起）
   主进程在拉起子进程前会校验其 Authenticode 签名（deploy/01 §1.3.4）。
5. 系统要求：Windows 10 1909（Build 18363）及以上 / Windows 11。
   不支持 Windows Server / LTSC 2019 / ARM64（R1 阶段）。

升级与备份：
- 升级包经 GPG + Authenticode 双重验签；数据库迁移单向不可回滚，升级器会先快照备份。
- 请定期用 "设置 → 备份与恢复 → 导出全案件备份" 导出 .stuchka-backup 到 U 盘 / 网盘。

  本安装器供已自行编译者使用（见仓库 README 构建说明）。
